How submission works

  1. Star the HammerDB project.
  2. Review the artifact preview.
  3. Copy the JSON if prompted.
  4. Click Open GitHub submission.
  5. Sign in to GitHub if prompted.
  6. Review the file contents.
  7. Commit the change and open the pull request.
